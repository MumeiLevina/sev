## 🚀 Hệ Thống Microservice Chuyển Đổi PDF Nâng Cao (`pdf-converter-service`)

Nằm tại thư mục `pdf-converter-service/`, đây là cụm dịch vụ phân tán, xử lý bất đồng bộ chịu tải cao dành cho các tác vụ chuyển đổi phức tạp (PDF sang Word DOCX, Excel XLSX, PowerPoint PPTX, RTF, EPUB, và Office sang PDF).

### Công Nghệ Nền Tảng:
- **FastAPI Gateway**: Tiếp nhận yêu cầu, kiểm tra an toàn định dạng (magic bytes), giới hạn 50MB, rate-limit 15 req/s.
- **MinIO (S3 Storage)**: Lưu trữ tạm thời các file tải lên và file kết quả với cơ chế tự động dọn dẹp (TTL 60 phút).
- **Redis & Celery**: Quản lý hàng đợi tác vụ bất đồng bộ, hỗ trợ mở rộng động (dynamic worker scaling).
- **LibreOffice unoserver daemon + Poppler C++**: Chuyển đổi chính xác 100% bố cục bảng biểu, vector và font chữ.

### Cách Khởi Chạy Dịch Vụ Microservice:
```bash
# Di chuyển vào thư mục dịch vụ
cd pdf-converter-service

# Khởi chạy toàn bộ hạ tầng bằng Docker Compose
docker-compose up -d --build

# Scale số lượng worker khi cần xử lý lượng tệp lớn
docker-compose up -d --scale worker-converter=4
```

### Các Cổng Dịch Vụ:
- **API & Tài liệu tương tác Swagger UI**: [http://localhost:8080/docs](http://localhost:8080/docs)
- **Bảng điều khiển lưu trữ MinIO S3 Console**: [http://localhost:9001](http://localhost:9001) *(User: `minioadmin` / Pass: `minioadmin123`)*
- **Kiểm tra trạng thái hệ thống**: [http://localhost:8080/health](http://localhost:8080/health)

### Chạy Kiểm Thử Tự Động Microservice:
```bash
python pdf-converter-service/test_service.py
```

## 💻 Hướng Dẫn Sử Dụng Web Tools

Để mở và sử dụng 30 công cụ phía máy khách:
1. Bạn có thể mở trực tiếp bất kỳ tệp `.html` nào (ví dụ: `index.html`) bằng trình duyệt (Chrome, Edge, Firefox).
2. Hoặc sử dụng một máy chủ tĩnh nội bộ:
   ```bash
   # Sử dụng Python
   python -m http.server 3000
   
   # Hoặc sử dụng Node.js npx serve
   npx serve .
   ```
   Sau đó truy cập: `http://localhost:3000`.
